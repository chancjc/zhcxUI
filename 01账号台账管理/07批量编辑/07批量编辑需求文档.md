# 账号台账管理-批量编辑需求文档

## 一、需求背景

- 当前 `账号台账管理` 列表中，多个来源渠道存在相同字段需要同步维护的场景，逐条进入编辑会增加操作成本。
- 业务需要提供统一的批量编辑能力，支持对已勾选来源渠道集中处理备注、运营模式、品牌信息和停用信息等字段，提升批量维护效率。
- 在批量处理过程中，还需要同时支持剔除不需要继续编辑的来源渠道，以及快速将同列内容同步到其它来源渠道，减少重复录入。

## 二、需求说明

**涉及页面**

- `账号台账管理` 列表页
- `账号台账管理` 批量编辑弹窗

**数据范围**

- 列表页当前勾选的来源渠道数据
- 批量编辑涉及字段：来源渠道、备注、运营模式、绑定品牌、品牌授权时间、品牌角色、品牌权益、授权异常情况备注、停用时间、停用原因、是否源头站点、是否整套停用、停用恢复时间、停用备注
- 弹窗打开时需带入当前勾选来源渠道上述字段的现有值
- 保存时更新当前批量编辑列表内来源渠道对应字段值
- 不包含账号台账列表筛选条件调整
- 不包含单个来源渠道详情页结构调整
- 不包含新增字段和字段定义变更

**批量编辑功能**

**页面入口**

- `批量操作` 按钮增加二级按钮 `批量编辑`

**入口校验**

- 未勾选任何来源渠道时，提示 `请至少勾选一条来源渠道后再进行批量编辑。`
- 当前勾选来源渠道超过 30 条时，提示 `当前勾选的来源渠道已超过 30 条，批量编辑最多支持 30 条，请调整勾选后重试`
- 校验未通过时，不打开批量编辑弹窗

**弹窗展示**

- 弹窗标题：`批量编辑`
- 弹窗展示已选来源渠道数量，格式为 `已选来源渠道：X / 30`
- 编辑处理上限提示文本：`单词最多批量编辑30条来源渠道`
- 弹窗打开时需带入列表选中来源渠道相关字段的现有值
- 弹窗内表格固定表头，内容区超过高度后纵向滚动
- 只读字段使用灰色背景区分

**弹窗操作**

- 删除选中：勾选不需要继续编辑的来源渠道，点击删除后从批量编辑列表中移除，已选来源渠道数量同步更新；未勾选任何行时点击 `删除选中`，提示 `请勾选需要移除编辑的来源渠道`
- 批量更新：列表表头增加 `批量更新` 按钮，点击批量更新按钮，以第一行内容为准，将第一行之后的所有行同列内容同步为第一行内容
- 取消：取消当前页面编辑内容，维持当前来源渠道相关字段现有字段值，不做更新
- 保存：保存当前页面编辑内容，更新对应来源渠道相关的字段值

**数据更新规则**

- 批量编辑的数据更新处理规则需与单记录编辑操作保持一致
- 涉及数据更新的批量编辑操作需记录操作日志
- 字段原值为空时，保存后按当前页面输入结果更新
- 字段原值已有内容时，若用户在编辑页面手动清空并保存，则对应字段更新为空值
- 字段原值已有内容时，若用户未修改该字段且直接保存，则保持原值不变

**批量编辑字段结构**

- 批量编辑字段结构如下表：

| 字段 | 展示方式 | 编辑方式 |
|---|---|---|
| 来源渠道 | 文本 | 只读 |
| 备注 | 文本域 | 可编辑 |
| 运营模式 | 下拉框 | 可选 `FBA / FBM / 混合 / -` |
| 绑定品牌 | 文本 | 只读 |
| 品牌授权时间 | 日期 | 可编辑 |
| 品牌角色 | 文本域 | 可编辑 |
| 品牌权益 | 文本域 | 可编辑 |
| 授权异常情况备注 | 文本域 | 可编辑 |
| 停用时间 | 日期时间 | 可编辑 |
| 停用原因 | 文本域 | 可编辑 |
| 是否源头站点 | 下拉框 | 可选 `是 / 否` |
| 是否整套停用 | 下拉框 | 可选 `是 / 否` |
| 停用恢复时间 | 日期时间 | 可编辑 |
| 停用备注 | 文本域 | 可编辑 |
