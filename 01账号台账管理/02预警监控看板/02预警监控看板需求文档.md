# 账号台账管理页面需求文档

## 1. 需求背景
为提升后台管理系统账号台账模块的数据可视化和查询效率，需重构“账号台账管理”页面。新页面需整合数据看板、高级搜索和数据列表，实现三者的联动筛选，提供更直观、紧凑的专业操作体验。

## 2. 页面整体布局
页面采用上下结构，从上至下依次为：
1. **数据看板区域**（紧凑型标题，支持折叠/展开）
2. **高级搜索面板**（支持常用/高级条件折叠切换）
3. **数据列表区域**（带分页和操作列）

## 3. 功能模块详细说明

### 3.1 数据看板区域 (图表视图)
看板区域包含四个指标模块，采用响应式网格布局，支持点击图表元素联动过滤下方表格数据。具体指标字段与取值逻辑如下：

*   **指标一：店铺状态（饼图）**
    *   **正常店铺**：筛选 `店铺状态` = `正常`
    *   **失败店铺**：筛选 `店铺状态` = `失败`
    *   **未处理店铺**：筛选 `店铺状态` = `未处理`
    *   **异常店铺**：筛选 `店铺状态` = `支付方式无效`

*   **指标二：休假模式（环形图）**
    *   **在售店铺数**：筛选 `休假模式` = `在售`
    *   **非在售店铺数**：筛选 `休假模式` = `非在售`
    *   **无采集数据店铺数**：筛选 `休假模式` = `无采集数据`

*   **指标三：运营模式（柱状图）**
    *   **混合模式店铺数**：筛选 `运营模式` = `混合`
    *   **纯FBA模式店铺数**：筛选 `运营模式` = `FBA`
    *   **纯FBM模式店铺数**：筛选 `运营模式` = `FBM`
    *   **未设置店铺数**：筛选 `运营模式` = `-` (横杠)

*   **指标四：预警类（进度条列表）**
    *   **近效期预警店铺数**：筛选 `EPR/欧代有效日期` 距离当前系统日期 `≤30天` 且 `≥0天`
    *   **过期预警店铺数**：筛选 `EPR/欧代有效日期` 小于当前系统日期（已过期）
    *   **侵权违规预警店铺数**：筛选 `侵权违规数` `> 0`
    *   **禁售违规预警店铺数**：筛选 `禁售违规数` `> 0`
    *   **政策警告预警店铺数**：筛选 `政策警告数` `> 0`
    *   **FBM业务员设置错误预警店铺数**：筛选 `FBM业务员设置错误` 的店铺
    *   **安全图片未上传预警店铺数**：筛选 `安全图片未上传` 的店铺

**交互要求**：
*   右上角提供“收起看板/展开看板”按钮，点击后平滑折叠/展开。
*   点击任意图表区块/进度条，下方表格自动筛选对应数据，并在搜索区显示“筛选标签”，支持点击“×”取消筛选。

### 3.2 高级搜索面板
提供 22 个搜索条件，支持模糊搜索、精确匹配、区间查询和日期范围查询。

*   **默认展示（常用条件）**：账号组、真实店铺名、店铺状态、休假模式、运营模式、近30天销量（区间）。
*   **折叠展示（高级条件）**：来源渠道、邮箱激活状态、API授权状态、发货单激活状态、刊登账号组状态、来源渠道状态、品牌授权时间（日期范围）、站点、账号所属部门、是否有VAT税号、绑定品牌、刊登账号组、FBA历史订单数（区间）、FBA在线链接数（区间）、30天购物车（区间）、是否整套停用。

**交互要求**：
*   提供“展开/收起更多条件”按钮切换展示状态。
*   与看板联动联动逻辑：当收起看板时，高级搜索条件自动展开显示全部（2行）；当展开看板时，高级搜索条件自动收起仅展示1行（常用条件），但仍可通过点击“展开更多条件 ▼”手动展开。
*   提供“查询”按钮执行搜索。
*   提供“重置”按钮清空所有输入框并取消看板图表的选中状态。

### 3.3 数据列表区域
展示账号台账明细数据。

*   **表格字段**：账号组、店铺名称、店铺状态（带颜色标签）、休假模式、运营模式、FBA业务员、近30天销量、添加时间、EPR/欧代有效期、侵权违规数、禁售违规数、政策警告数、操作（查看、编辑）。
*   **预警高亮**：侵权、禁售违规数大于 0 时标红，政策警告数大于 0 时标黄。
*   **分页功能**：支持切换每页展示条数（10/20/50），支持上一页/下一页切换，显示总记录数和当前页码。

## 4. 非功能性需求
*   **UI 风格**：简洁专业的后台风格，主色调为蓝色（`#1890ff`），搭配浅色背景和卡片阴影。
*   **响应式**：图表和搜索面板需根据浏览器窗口大小自动适配（ECharts `resize`）。
*   **技术栈**：原生 HTML + CSS + JavaScript，图表使用 ECharts (CDN 引入)。
*   **性能**：看板折叠、高级搜索展开需有平滑的 CSS 过渡动画。
